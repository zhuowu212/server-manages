# 资产文件协议 v1

依据：spec FR-008、FR-014..016；这是既有导入/导出功能的精确契约，不新增业务字段。

## 格式及版本

- 模板支持xlsx/xls/csv；导出仅xlsx/csv。Excel只有一个非空数据sheet。
- 第一行元数据为四个文本单元：`模板版本`、`1`、`文本转义`、`none`。
  CSV安全导出把第四项改为`apostrophe-v1`；Excel和空模板均为`none`。
- 第二行为下表精确的21个中文列名；第三行起为数据。版本及表头不计入5000数据行上限。
  用户可调整列顺序，解析按唯一列名映射；生成的模板/导出严格按表中顺序。
  全部表头都必须存在，可选字段值可空，额外、重复或缺失列均拒绝；不猜测英文别名。
- CSV为UTF-8，可带BOM，标准双引号、逗号、换行及双引号转义；单元格内换行按一个CSV记录处理。
  CSV错误“行号”指从1起的逻辑记录号（版本1、表头2、首条数据3），Excel指实际sheet行号。
- 空文件或仅元数据/表头而无数据返回422 `EMPTY_IMPORT`。缺/非法版本返回422 `TEMPLATE_VERSION_INVALID`；
  不支持版本返回422 `TEMPLATE_VERSION_UNSUPPORTED`；非法表头返回422 `TEMPLATE_HEADER_INVALID`；
  UTF-8解码错误返回422 `CSV_ENCODING_INVALID`，不猜测其他编码，不回显文件内容。
- `.xlsx/.xls`公式、宏、外链、加密文件或签名/格式不匹配拒绝；数值型编号/序列号/主机名须改为文本，
  不自动推测已丢失的前导零。模板中的业务单元格预设文本格式，资源限制仍执行FR-014。

21列恰好覆盖全部资产业务字段；不加入UUID、version、created_at、updated_at、账号信息、
密码、密码哈希、私钥、令牌、审计或未来采集来源元数据。必填/适用性以spec FR-008为准。
IP去除各项首尾空格再按实际地址验证，重复或空白项按统一校验反馈；空可选单元格规范为NULL/空集合。
文件包含外部凭据引用须明确提示敏感性和安全保管；日志、错误CSV及审计不得复制引用原文。

## CSV公式防护与无损往返

`apostrophe-v1`模式对每个非空数据单元格一律前置一个ASCII单引号，再执行标准CSV引号转义；
空单元格仍为空。例如原值`=SUM(1,2)`输出`'=SUM(1,2)`，原值`'abc`输出`''abc`。
导入仅在元数据明确为该模式时移除恰好一个前置单引号，缺少该前缀的非空单元格拒绝，
不得启发式猜测或移除用户原值中的其他引号。`none`模式按原文字读取，不执行内容。
Excel导出用字符串单元格而非公式；CSV中的类型、状态、日期等同样按文本编码，避免例外分支。

测试须包含`= / + / - / @`起始值、制表符、回车、前置单引号、逗号、双引号、多行文本和前导零。
往返测试先比较解析后的规范业务值，再使用隔离空库验证导入；向已有库重导重复资产仍按FR-015拒绝，
不得为往返方便而改成更新既有资产。

## 导出预览及下载反馈

预览回显：格式、范围filtered/all、规范化q/type/status/environment/region/owner、排序（如有）、冻结时刻、
数量、模板版本及21列。`all`明确忽略筛选，`filtered`忽略page/page_size但保留筛选，不静默更换快照。

| 场景 | 用户可见结果 | 服务端结果及保留 |
| --- | --- | --- |
| 无命中 | 无可导出数据 | 422 NO_EXPORT_DATA，不创建文件 |
| 确认前取消 | 已取消导出，未开始生成 | 本地取消不创建作业/伪成功审计 |
| 生成中/生成完成 | 正在生成/文件已生成，可下载 | started/success表示生成阶段，不表示客户端已保存 |
| 生成失败 | 导出失败，可修正后重试 | failed，不发布损坏文件 |
| 下载开始前失败 | 下载失败，可重试 | 结构化错误并审计failed |
| 服务器传输中断 | 传输中断；可重新下载 | interrupted，不伪造完成；有效产物仍保留 |
| 服务器发送完成 | 服务器传输完成，请检查本地保存 | transferred，client_saved=unknown |
| 浏览器取消保存框 | 未确认本地保存，可重新下载 | 服务器无法感知时保持unknown，不伪造cancelled |
| 产物过期 | 文件已过期，请重新导出 | 410 EXPORT_EXPIRED，不重建不同数据集 |

首版不增加后台作业取消API；已生成产物沿用24小时技术保留期。每次下载均重验当前权限及所有者，
不能仅凭UUID访问。传输开始后的错误不能再发送伪造JSON成功响应；摘要遵循audit-events.md。
